## Context

When a user texts/pastes a shareable URL, the receiving app's crawler reads the page `<head>` for
Open Graph tags to render an unfurl card. Two gaps make every link preview as "function bucket":

1. **No `og:*`/`title` meta is set** on any in-scope page (`auth-app/app/app.vue` sets no title;
   `go/[id].vue`, `set-password.vue`, `verify-email.vue` set none).
2. The one page with a per-link label — `apps/auth-app/app/pages/go/[id].vue` — fetches it
   **client-side in `onMounted`** (verified: lines 61–86), where a JS-less crawler never sees it.

The `subjectLabel` already flows through to the landing page (cached on `auth.deep_link`, passed by
`shareToLink(urn, tree.name)` in `todo/[id].vue:128` and `shareToLink(p.urn, p.title)` in
`poll/[id].vue:124`) — so the label content is free; only its **delivery into SSR `<head>`** and its
**formatting** are new.

**Locked decisions** (spec README L1–L7): scope = OTP deep links + invite ceremony links (raw
detail / asset links out); wording = noun + title (`Poll: …`, `Todo: …`); the prefix/icon/description
live in a **per-module registry** extending `urn-route.ts` (the cached label stays the bare name);
OTP preview is **SSR-rendered**; description carries **no tenant name** (enumeration safety); invite
preview is **static/generic** (no token read); `og:image` = one branded asset.

`useSeoMeta` is Nuxt-auto-imported (confirmed in every app's `.nuxt/imports.d.ts`).

## Fix approach

### Phase 1 — the per-module presentation registry (`shared/utils/urn-route.ts`)
Anchor: `apps/auth-app/shared/utils/urn-route.ts` (today `module → route`, entries todo + poll).
- Extend to the single presentation source per `_shared.data.md` §1: a `MODULES` map
  `module → { route, previewNoun, icon, ogDescription }` (+ a `FALLBACK`), with **`resolveUrnRoute`
  derived from it — same signature, same behavior** (it is consumed by `server/api/otp/verify.post.ts`
  and the landing's logged-in switch; do not change its contract).
- Add `modulePresentation(module)` and the pure `buildPreview({ module, subjectLabel })` →
  `{ title, description }` (L2: `${previewNoun}: ${label}`, or the noun alone when label-less; L5:
  registry description, **no tenant name**).
- `[FILL IN]` verify the poll `icon` (`i-lucide-bar-chart-3`?) against the iconify set (UC11).
- Barrel note: `shared/utils/` is auto-imported (`#shared/utils/urn-route`) — no barrel line to add.

### Phase 2 — OTP deep-link preview, SSR (`go/[id].vue`)
Anchor: `apps/auth-app/app/pages/go/[id].vue` (`onMounted` fetch lines 61–86; `itemLabel` 40–44).
- Move the `otp/link` public-projection fetch from `onMounted` to **`useAsyncData`** so it runs
  during SSR (`_shared.data.md` §3 / `go-preview.data.md`). Keep the existing dead-link /
